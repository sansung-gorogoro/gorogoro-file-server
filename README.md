# File Server (LXP)

## 📌 소개
- 대용량 파일 업로드 처리를 위한 구조를 탐구하며 독립적으로 구현한 파일 서버입니다.
- 업로드 시 발생하는 재전송 및 실패 문제를 해결하기 위해 설계되었습니다.

---

## 👨‍💻 담당 역할
- 파일 서버 설계 및 구현
- 청크(Chunk) 기반 업로드 구조 설계
- 업로드 재개(Resume) 기능 구현

---

## ⚙️ 주요 기능
- 대용량 파일 업로드 지원
- Chunk 단위 업로드 처리
- 업로드 세션 기반 상태 관리
- 업로드 중단 후 재개 기능

---

## 🧠 설계 포인트

### 1. Chunk 기반 업로드
파일을 여러 조각으로 나누어 전송하여 대용량 업로드 시 실패 리스크를 최소화

### 2. 업로드 세션 기반 상태 관리
업로드 진행 상태(offset)를 서버에서 관리하여 중단된 지점부터 재전송 가능하도록 설계

### 3. 서버 분리 구조
파일 업로드를 API 서버와 분리하여 파일 처리 책임을 독립적으로 관리

### 4. 무결성 검증
- 업로드 완료 후 해시 기반 검증을 통해 파일 손상 여부 확인
- Chunk 업로드 시 offset 검증을 통해 잘못된 순서의 업로드를 방지하여 데이터 일관성 확보
